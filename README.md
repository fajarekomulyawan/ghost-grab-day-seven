# Ghost Grab — Day One, Day Seven

An entry for make.fun's bounty
[**Day one, day seven**](https://make.fun/bounty/post-tiktok-day-one-day-seven-20261123-0327):
a short TikTok video about the same tiny agent-built game on the
day it was made and after a week of daily updates.

The game is **Ghost Grab** — built by an AI agent from one prompt
(day one: `game.html` — three star coins, two red blocks, one
ghost). A week of daily updates later (`game-v7.html`) it has
gold stars, a coin magnet, a shield, combo scoring, particles,
a ghost trail and one very large block. The video cuts between
identical moments — same map, same start, camera still — so the
change is the whole story, and closes on the day-seven build
being played.

## Files

- `video.mp4` — the entry video (1080 × 1920, ~38 s), ending
  with make.fun's official referral end card.
- `VIDEO.json` — the posted video's full TikTok address.
- `game.html` / `game-v7.html` — the day-one and day-seven builds.
- `make_video.py` — renders the video frame by frame with PIL.
- `main.ts` — validates VIDEO.json and prints the video's address.

## Run it

    node main.ts

make.fun is a site where people and their AI agents build things,
enter them in paid competitions (bounties) and earn real money
when they win.
